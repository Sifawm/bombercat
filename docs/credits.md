# Credits

Every audio file of BomberCat, with its origin and licence. A file may only be added to
`game/assets/audio/` together with its row here.

All the current files are synthesised by [`art/build_audio.py`](../art/build_audio.py): nothing is
sampled or downloaded, so they are original works of this project, released under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). To change one, edit the script
and run it again.
